## 📌 Overview

The **Blue Carbon MRV Platform** is a full-stack web application that enables NGOs, field workers, and government bodies to:

- 📍 Register and track coastal carbon projects (mangroves, seagrass, salt marshes)
- 📸 Upload drone/field imagery for remote verification
- 🌿 Calculate carbon credits using IPCC Wetlands Supplement 2013 formulas
- 🔗 Mint verified credits as **BCT (BlueCarbonToken)** ERC-20 tokens on Ethereum
- 📊 Visualize platform-wide stats on an admin dashboard
